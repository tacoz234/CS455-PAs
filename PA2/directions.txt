Objective:
Your main in p2.c should open, read, then display the contents of a .pcap file that contains an unspecified number of captured packets. The output must follow a strict format (it will be diffed against the expected output. Follow the examples shown in the sample runs illustrated below.

PCAP File Format:   
https://wiki.wireshark.org/Development/LibpcapFileFormatLinks to an external site.
 

Notice that the output of printIPinfo() :  You display the IP header length and the number of option bytes as well. Also, at the end of the line of an IP packet,  (i.e. after any UDP, TCP, or ICMP information) the size of AppData value is displayed using "%5u"

In addition, UDP and TCP information is now printed in some specific format using two new required functions:
printUDPinfo
printTCPinfo

UDP Information to print:
Total Length of the UDP datagram in bytes.
Source and Destination ports in numeric using "%5u"  .
Source and Destination port names using "(%7s)" format, or "(   *** )"   if port has no standard name.
Should expect any of the many many service names, so use a library function to convert port numbers into service names.

TCP Information to print:
TCP Header Length in bytes, and how many of these bytes are TCP header options.
Source & Destination ports numerical & names as described  in UDP above.
Flags as "[SYN PSH ACK FIN RST ]" in that order. If a flag is not set, print 4 spaces instead,
as in [SYN ____ACK FIN ____] .
Sequence number using "%10u".
When applicable, the Acknowledgement number using "%10u". Otherwise, print 15 spaces.
The receive window size using "%5hu".
