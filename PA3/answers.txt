Question 1: How do you decide that an Ethernet frame is targeting your machine?
An Ethernet frame targets your machine if its destination MAC address matches one of your interface MAC addresses or if it is the Ethernet broadcast address (ff:ff:ff:ff:ff:ff).

Question 2: Next, how do you determine that it's an ARP request asking about your machine's MAC address?
To determine if it's an ARP request for your machine, you check if the Ethernet Type is 0x0806 (ARP), the ARP Operation is 1 (ARPREQUEST), and the Target Protocol Address (TPA) matches one of your assigned IP addresses.

Question 3: How do you determine it's a proper ICMP echo request targeting your machine?
A proper ICMP echo request targeting your machine has an Ethernet Type of 0x0800 (IPv4), an IP Protocol of 1 (ICMP), a Destination IP address matching one of your IPs, and an ICMP Type of 8 (Echo Request) with a Code of 0.

Question 4: Which fields of the outgoing packet's IP header need to be modified?
The following fields in the IP header must be modified for an Echo Reply:
- Source and Destination IP addresses (must be swapped)
- Identification (set according to the requirement, e.g., starting at 1000 and incrementing)
- Flags (set to "Do Not Fragment" or 0x4000)
- Time to Live (TTL) (typically set to a default value like 64)
- Header Checksum (must be recalculated)

Question 5: Do you need to recalculate the checksum of the IP header? of the ICMP message? or both?
Both checksums must be recalculated. The IP header checksum changes because multiple header fields (IPs, ID, Flags) were modified. The ICMP checksum changes because the ICMP Type field was changed from Echo Request (8) to Echo Reply (0).
